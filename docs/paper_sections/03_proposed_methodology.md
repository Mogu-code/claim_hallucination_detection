### III. PROPOSED SYSTEM ARCHITECTURE AND METHODOLOGY

This section presents the formal design of our evidence-aware claim-level hallucination detection architecture. Following the research focus of this project, the methodology centers on resolving the **Evidence Sufficiency Gap**—the systematic failure that occurs when retrieval similarity is treated as evidence of factual entailment. 

#### A. Mathematical Problem Formulation
Let $r$ denote an unstructured text response generated by an autoregressive language model, and let $\mathcal{C}_{\text{corpus}} = \{p_1, p_2, \dots, p_K\}$ denote an indexed reference evidence corpus composed of factual document passages. 

The verification system executes a structured mapping:
$$r \xrightarrow{\text{Verification Pipeline}} \left( \{c_i\}_{i=1}^n, \{y_i\}_{i=1}^n, \{\mathcal{T}_i\}_{i=1}^n, H(r) \right)$$
where:
* $\{c_1, c_2, \dots, c_n\}$ represents the set of discrete, self-contained atomic propositions extracted from response $r$.
* $y_i \in \{\text{Supported}, \text{Contradicted}, \text{Unsupported}\}$ denotes the categorical verification label assigned to proposition $c_i$.
* $\mathcal{T}_i = (c_i, p^*_i, s^*_i, P_{\text{ent}}, P_{\text{contra}}, P_{\text{neu}}, y_i)$ denotes an auditable evidence-decision trace linking the claim to its top evidence passage $p^*_i$ and raw model probabilities.
* $H(r) \in [0, 1]$ represents the aggregate, response-level hallucination score, defined as the proportion of non-supported propositions:
$$H(r) = \frac{n_{\text{Contradicted}} + n_{\text{Unsupported}}}{n} = \frac{1}{n} \sum_{i=1}^n \mathbb{I}(y_i \neq \text{Supported}) \quad \text{(1)}$$
A response with $H(r) = 0$ is completely verified and grounded by corpus evidence, whereas $H(r) = 1.0$ indicates that all extracted claims either directly contradict factual records or lack evidentiary support.

#### B. Module 1: Syntactic Atomic Claim Decomposition
Evaluating complex, multi-clause paragraphs monolithically introduces confounding variables because accurate factual assertions are conflated with isolated erroneous clauses. Conversely, splitting sentences strictly on punctuation fragments dependent subordinate clauses, producing dangling pronouns (e.g., *"She was awarded..."*) that fail when retrieved independently.

We implement a deterministic, rule-guarded syntactic clause splitter:
1. **Sentence Boundary Guarding:** Segments response $r$ into sentences while preserving common abbreviations, numerical decimals, honorifics (e.g., *"Dr."*, *"Prof."*), and institutional titles.
2. **Coordinating Conjunction Splitting:** Detects compound coordinate clauses connected by conjunctions (*"and"*, *"but"*, *"whereas"*). Conjunction splitting is guarded by strict part-of-speech requirements: a split is executed if and only if both the left-hand and right-hand substrings contain independent subject–verb predicates and exceed a minimum clause length threshold ($\ge 4$ tokens). This prevents erroneous splits across noun compounds (e.g., *"Physics and Chemistry"* remains a unified argument).
3. **Pronominal Subject Resolution:** When an extracted proposition begins with an anaphoric third-person pronoun (*"he"*, *"she"*, *"it"*, *"they"*), the pronoun is deterministically resolved using the most recent explicit nominal subject identified in preceding clauses.
4. **Trivial Fragment Elimination:** Filters out conversational filler, discourse connectives (e.g., *"Furthermore"*, *"In conclusion"*), and single-word fragments ($<3$ tokens).

#### C. Module 2: Dense Passage Indexing and Semantic Retrieval
To evaluate whether factual evidence exists for each proposition without incurring the extreme latency of external web search engines, we implement dense semantic retrieval across chunked reference corpora.

Let each reference document be divided into fixed-length passages $\{p_j\}_{j=1}^K$ using a sliding window with sentence overlap. A dense dual-encoder maps each passage $p_j$ into a normalized $d$-dimensional embedding vector $\mathbf{v}_j \in \mathbb{R}^d$:
$$\mathbf{v}_j = \frac{\mathbf{E}_{\text{dense}}(p_j)}{\|\mathbf{E}_{\text{dense}}(p_j)\|_2}$$
For each extracted claim $c_i$, its query embedding is identically computed:
$$\mathbf{q}_i = \frac{\mathbf{E}_{\text{dense}}(c_i)}{\|\mathbf{E}_{\text{dense}}(c_i)\|_2}$$
The semantic similarity between claim $c_i$ and passage $p_j$ is given by the cosine inner product:
$$\text{sim}(c_i, p_j) = \mathbf{q}_i^\top \mathbf{v}_j$$
Evidence retrieval identifies the top-$k$ nearest passages $\mathcal{P}_k(c_i) = \{p_{i,1}, \dots, p_{i,k}\}$ maximizing cosine similarity. In distractor-rich evaluation pools, passages from all available reference documents are pooled together, requiring retrieval to identify the specific source document among distractors.

#### D. Module 3: Bidirectional Cross-Encoder NLI Verification
Bi-encoder embeddings compress sentences into isolated vectors, losing fine-grained cross-token interactions necessary to detect subtle factual contradictions (such as swapped dates or inverted negations). Therefore, we employ a bidirectional cross-encoder Natural Language Inference (NLI) model to perform deep premise–hypothesis alignment.

For each retrieved passage $p_j \in \mathcal{P}_k(c_i)$, the cross-encoder concatenates the passage as the premise and the proposition $c_i$ as the hypothesis, computing full bidirectional cross-attention across all tokens. The classification head outputs unnormalized logits $\mathbf{z} = [z_{\text{ent}}, z_{\text{contra}}, z_{\text{neu}}]^\top$, converted to normalized probabilities via softmax:
$$P(\text{class} \mid p_j, c_i) = \frac{\exp(z_{\text{class}})}{\sum_{c' \in \{\text{ent}, \text{contra}, \text{neu}\}} \exp(z_{c'})}$$
Dynamic sequence-length bucketing is applied during batch inference: candidate pairs are sorted by composite character length prior to tokenization, drastically minimizing padding overhead.

#### E. Module 4: Dynamic Calibrated Threshold Fusion Gate
Standard NLI classifiers default to a symmetric $\arg\max$ decision rule. However, in factual hallucination verification, the operational costs of errors are highly asymmetric: falsely accepting an unverified or contradicted claim compromises clinical or legal safety, whereas a false neutral classification simply requests further human verification.

We establish three independent, asymmetric decision thresholds:
* $\tau_{\text{contra}} \in [0, 1]$: The contradiction threshold. Because a single explicit factual contradiction invalidates a claim regardless of other neutral passages, contradiction takes precedence.
* $\tau_{\text{ent}} \in [0, 1]$: The entailment threshold required to confirm that evidence actively proves the proposition.
* $\tau_{\text{sim}} \in [0, 1]$: The minimum retrieval similarity bound, acting as a gating constraint to ensure the candidate passage is topically relevant before entailment can be credited.

Let $p^* = \arg\max_{p_j \in \mathcal{P}_k(c_i)} P_{\text{ent}}(p_j, c_i)$ be the passage exhibiting maximum entailment probability, and let $s^* = \text{sim}(c_i, p^*)$ be its retrieval similarity. The formal verification decision rule is defined as:
$$y(c_i) = \begin{cases}
\text{Contradicted}, & \text{if } \max_{p_j \in \mathcal{P}_k} P_{\text{contra}}(p_j, c_i) \ge \tau_{\text{contra}} \\
\text{Supported}, & \text{else if } P_{\text{ent}}(p^*, c_i) \ge \tau_{\text{ent}} \land s^* \ge \tau_{\text{sim}} \\
\text{Unsupported}, & \text{otherwise}
\end{cases} \quad \text{(2)}$$
Setting $\tau_{\text{sim}} = 0$ removes the similarity gate, yielding the pure NLI verifier. Setting $\tau_{\text{contra}} = 1.0$ and $\tau_{\text{ent}} = 0$ yields the similarity-only baseline, allowing systematic ablation of the Evidence Sufficiency Gap.

#### F. Module 5: Adaptive Scalar Reasoning Module
Standard pre-trained cross-encoder models frequently fail on numerical propositions involving scalar bounds, monotonic subsumption, and strict temporal exclusion. For example, if evidence states *"Yale University has 20 living billionaire alumni"*, standard NLI models predict *Neutral* when evaluating the claim *"Yale has 5 living billionaire alumni"* ($P_{\text{ent}} \approx 0.0169$), despite the fact that possessing 20 living billionaires mathematically entails possessing 5.

To resolve these systematic failures, we integrate an adaptive scalar reasoning module that audits numerical quantities and associated noun units:
1. **Quantity and Unit Extraction:** Parses numeric integers, decimals, and English word numerals along with their adjacent head nouns (e.g., $N_{\text{ev}} = 20, \text{unit} = \text{``alumni''}$; $N_{\text{claim}} = 5, \text{unit} = \text{``alumni''}$).
2. **Monotonic Scalar Subsumption:** When compatible units match in affirmative contexts without restrictive adverbs (*"only"*, *"exactly"*), the system evaluates:
$$\text{If } N_{\text{ev}} \ge N_{\text{claim}} \implies P_{\text{ent}} \leftarrow \max(P_{\text{ent}}, 0.85)$$
3. **Temporal Incompatibility Check:** For exclusive historical events where year entities conflict ($|\text{Year}_{\text{ev}} - \text{Year}_{\text{claim}}| \ge 1$), the module forces refutation ($P_{\text{contra}} \leftarrow \max(P_{\text{contra}}, 0.90)$), preventing subtle temporal hallucinations from slipping through.

```
Algorithm 1: Evidence-Aware Claim-Level Verification Pipeline
Input : Response r, Evidence Corpus C, Top-k retrieval depth k,
        Calibrated thresholds (tau_ent, tau_contra, tau_sim), Scalar flag use_scalar
Output: Claim verdicts {y_i}, Trace set {T_i}, Response Hallucination Score H(r)
1  Decompose response r into atomic propositions: C = {c_1, c_2, ..., c_n}
2  for each atomic claim c_i in C do
3      Query indexed corpus C to retrieve top-k passages: P_k(c_i) = {(p_j, s_j)}_{j=1}^k
4      for each candidate passage p_j in P_k(c_i) do
5          Compute cross-encoder probabilities: [P_ent, P_contra, P_neu] = NLI(p_j, c_i)
6          if use_scalar is True then
7              [P_ent, P_contra] = ApplyScalarReasoning(p_j, c_i, P_ent, P_contra)
8      end
9      Identify max contradiction: P_con_max = max_j P_contra(p_j, c_i)
10     Identify max entailing passage: p* = argmax_j P_ent(p_j, c_i) with similarity s*
11     if P_con_max >= tau_contra then
12         y_i <- Contradicted
13     else if P_ent(p*, c_i) >= tau_ent and s* >= tau_sim then
14         y_i <- Supported
15     else
16         y_i <- Unsupported
17     Record audit trace: T_i <- (c_i, p*, s*, P_ent, P_con_max, y_i)
18 end
19 Compute response hallucination score: H(r) = (n_Contradicted + n_Unsupported) / n
20 return {y_i}_{i=1}^n, {T_i}_{i=1}^n, H(r)
```

#### G. Transparent Audit Trace Architecture
For every audited proposition, the system generates a structured audit trace receipt containing:
$$\mathcal{T}_i = \left( \text{ID}, c_i, p^*, s^*, P_{\text{ent}}, P_{\text{contra}}, P_{\text{neu}}, \tau_{\text{applied}}, y_i, \text{Rationale} \right)$$
This transparent trace allows human auditors, clinical reviewers, and researchers to verify the exact evidence passage utilized, examine the model's confidence distribution, and inspect threshold margins, providing full interpretability absent in black-box hallucination detectors.
