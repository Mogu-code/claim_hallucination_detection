## 1. Field of the Invention

The present invention relates generally to artificial intelligence and natural language processing (NLP). More specifically, the invention relates to automated systems and computer-implemented methods for detecting, localizing, and scoring factual hallucinations in text generated by autoregressive Large Language Models (LLMs) via atomic claim decomposition, dense passage retrieval, cross-encoder natural language inference (NLI), dynamic threshold fusion, and adaptive scalar reasoning.

---

## 2. Background of the Invention and Prior Art Disadvantages

Autoregressive Large Language Models (LLMs) synthesize natural language by sequentially predicting token probability distributions. Despite substantial fluency, LLMs suffer from a pervasive reliability failure termed "hallucination," wherein the generated content is factually untruthful, ungrounded, or in direct contradiction with verified external evidence.

Existing approaches to hallucination detection suffer from severe technical drawbacks:
1. **Monolithic Analysis:** Prior verification systems evaluate entire multi-sentence paragraphs as a single composite unit. Because generated text often combines accurate contextual background with an isolated factual falsehood, monolithic classifiers fail to localize errors and produce high false-positive rates.
2. **Stochastic Sampling Weakness:** Reference-free methods (e.g., SelfCheckGPT) evaluate the internal variance of stochastic completions without external grounding. When an LLM possesses entrenched parametric biases, it consistently regenerates the exact same hallucination across repeated samples, completely escaping detection.
3. **Extreme Latency and API Dependency:** Tool-based systems (e.g., SAFE, FacTool) require multi-turn queries to commercial web search engines and closed proprietary LLMs, resulting in prohibitive monetary cost and execution latencies exceeding 15 seconds per response.
4. **Failure in Scalar/Numerical Reasoning:** Contemporary cross-encoders treat scalar subsumption (e.g., asserting a subset of a verified larger quantity) as "Neutral," mistakenly flagging factual truths as unverified.

Accordingly, there is an unmet need for a fast, localizable, evidence-aware system that verifies atomic factual propositions with calibrated asymmetric thresholding and scalar bound reasoning.

## 3. Summary of the Invention

The present invention provides a computer-implemented system and method that transforms unstructured LLM-generated responses into verified, interpretable factual assessments.

Briefly, the method comprises:
1. Parsing an LLM-generated text response into atomic factual claims using a rule-guarded syntactic parser that selectively splits on coordinate conjunctions only when followed by explicit verb phrases.
2. Indexing a corpus of evidence passages into dense vector embeddings using a bi-encoder representation model and retrieving top-$k$ nearest passages for each atomic claim via cosine similarity.
3. Conducting bidirectional cross-encoder Natural Language Inference (NLI) on each claim-evidence pair with sequence-length bucketing to extract entailment, contradiction, and neutral probabilities.
4. Applying a dynamic threshold decision function calibrated on disjoint tuning data, classifying claims into *Supported*, *Contradicted*, or *Unsupported* categories.
5. Augmenting verification with an adaptive scalar reasoning module that computes numerical bound subsumption and exclusive temporal date matching.
6. Calculating an aggregated response-level Hallucination Score:
   $$\text{Hallucination Score} = \frac{\text{Count}(\text{Contradicted}) + \text{Count}(\text{Unsupported})}{\text{Total Atomic Claims}}$$

## 5. Detailed Description of the Preferred Embodiments

### 5.1 Claim Decomposition Unit
The input response $R$ is processed by a linguistic filter. Standard sentence splitters preserve compound coordinate clauses containing multiple independent propositions. The decomposition unit detects coordinate conjunctions (`and`, `but`) and applies part-of-speech guards: a split is executed if and only if the right coordinate contains an active or passive verb phrase. Noun compound conjunctions (e.g., *"won prizes in physics and chemistry"*) are preserved without fragmentation.

### 5.2 Dense Evidence Retrieval Unit
Evidence text is partitioned into overlapping chunks (3 sentences per chunk, 2-sentence stride). Bi-encoder $\mathbf{E}(\cdot)$ maps passages into 384-dimensional unit vectors. For query claim $c_i$, the system calculates dense dot products against all pre-indexed passage embeddings $\mathbf{v}_j$. The top-$k$ passages with the highest cosine similarity are retrieved. In empirical tests on distractor pools of 149 passages, this achieves a 94.51% Source-Document Hit Rate@1.

### 5.3 Cross-Encoder NLI & Length-Sorted Batching
Candidate pairs $(p_j, c_i)$ are grouped by cumulative character length before batching. This sequence-length sorting eliminates dynamic padding overhead on CPU/GPU hardware, yielding a ~6× runtime acceleration. The cross-encoder computes unnormalized logits $\mathbf{z} = \mathbf{f}_{\text{NLI}}(p_j, c_i)$, generating normalized softmax probabilities $[P(\text{ent}), P(\text{contra}), P(\text{neu})]$.

### 5.4 Calibrated Dynamic Thresholding
Unlike conventional argmax classification, decisions are governed by asymmetric thresholds tuned on disjoint data:
* If $P(\text{contra}) \ge 0.40 \implies \text{Contradicted}$.
* Else if $P(\text{ent}) \ge 0.40 \land \text{sim} \ge 0.20 \implies \text{Supported}$.
* Else $\implies \text{Unsupported (Not Enough Info)}$.

### 5.5 Adaptive Scalar Reasoning Unit
When a claim asserts a numerical count $N_{\text{claim}}$ and the evidence confirms $N_{\text{ev}}$ with compatible noun units:
* If $N_{\text{ev}} \ge N_{\text{claim}}$ in an affirmative context, the system overrides neutral cross-encoder predictions to output *Supported* ($P(\text{ent}) \leftarrow 0.85$).
* If an exclusive temporal fact asserts $|\text{Year}_{\text{ev}} - \text{Year}_{\text{claim}}| \ge 1$, the system overrides predictions to output *Contradicted* ($P(\text{contra}) \leftarrow 0.90$).

## 6. Patent Claims

**WE CLAIM:**

1. **A computer-implemented method for detecting hallucinations in machine-generated text, comprising:**
   - receiving, by a computing processor, an unstructured text response generated by an autoregressive Large Language Model (LLM);
   - decomposing the received text response into a plurality of standalone atomic claims using syntactic clause boundary detection guarded by verb-phrase validation;
   - retrieving, for each atomic claim, one or more relevant evidence passages from a pre-indexed evidence corpus using a dense vector bi-encoder;
   - calculating bidirectional cross-encoder Natural Language Inference (NLI) probabilities across entailment, contradiction, and neutral classes for candidate pairs of said atomic claims and retrieved evidence passages;
   - classifying each atomic claim as *Supported*, *Contradicted*, or *Unsupported* using asymmetric decision thresholds tuned on disjoint calibration data; and
   - generating an aggregated response-level Hallucination Score based on the proportion of non-supported atomic claims.

2. **The method of claim 1,** wherein decomposing the text response comprises identifying coordinating conjunctions (`and`, `but`) and executing a proposition split only when a right-side coordinate contains an active or passive verb phrase, while preventing fragmentation of compound noun phrases.

3. **The method of claim 1,** wherein candidate pairs of atomic claims and retrieved evidence passages are sorted by sequence character length prior to tensor batching, thereby minimizing dynamic padding overhead during transformer inference.

4. **The method of claim 1,** further comprising an adaptive scalar reasoning step wherein a numerical quantity extracted from an atomic claim is compared against a numerical quantity in the retrieved evidence, such that evidence quantities strictly subsuming claim quantities are classified as *Supported*.

5. **The method of claim 1,** wherein evidence retrieval executes over overlapping sentence-level passages chunked with a predetermined sentence count and stride.

6. **A system for claim-level hallucination detection in LLM generations, comprising:**
   - a memory storing instructions; and
   - one or more processors configured to execute the instructions to operate:
     - a Syntactic Claim Decomposition Module configured to segment composite text responses into atomic propositions;
     - a Dense Evidence Retrieval Engine configured to map passage chunks into normalized vector embeddings and retrieve nearest neighbors via cosine similarity;
     - a Cross-Encoder Inference Engine configured to compute bidirectional cross-attention probabilities across entailment, contradiction, and neutral classes;
     - an Adaptive Scalar Reasoner configured to evaluate numerical bounds and temporal consistency between claims and evidence; and
     - a Dynamic Threshold Fusion Module configured to output categorical claim labels and an interpretable Hallucination Score.

7. **The system of claim 6,** wherein the Cross-Encoder Inference Engine operates sequence-length sorting to minimize dynamic padding latency.

8. **The system of claim 6,** wherein the Adaptive Scalar Reasoner overrides neutral cross-encoder predictions to assign an entailment probability when an evidence quantity is greater than or equal to a claim quantity in non-exclusive affirmative contexts.

9. **A non-transitory computer-readable storage medium** storing instructions that, when executed by one or more processors, cause the processors to perform the steps of:
   - decomposing an LLM text output into atomic claims;
   - retrieving dense nearest-neighbor evidence passages;
   - evaluating cross-encoder NLI probabilities under sequence-length sorted batching;
   - verifying scalar numerical bounds between claims and evidence; and
   - determining claim labels using calibrated asymmetric thresholding.

10. **The storage medium of claim 9,** wherein the claim classification achieves improved pairwise discrimination accuracy compared to whole-paragraph monolithic verification.

## 7. Abstract of the Disclosure

A system and computer-implemented method are disclosed for detecting and localizing factual hallucinations in text generated by Large Language Models (LLMs). The system decomposes composite responses into atomic factual assertions using verb-guarded syntactic clause parsing. Evidence passages are retrieved from a pooled corpus via dense bi-encoder embeddings. Candidate claim-evidence pairs are batched with sequence-length bucketing to eliminate padding overhead, and scored via bidirectional cross-encoder Natural Language Inference (NLI). An asymmetric threshold decision rule and an adaptive scalar reasoner evaluate propositions into Supported, Contradicted, or Unsupported classes, resolving numerical subsumption errors and boosting pairwise hallucination discrimination (from 20.00% to 70.00% accuracy, AUROC from 0.5500 to 0.7700) over monolithic paragraph verification.
